Marble Allstars Tools

Blender add-on for drop-testing, playtesting and designing marble levels.

Download add-on (zip)

Blender 4.0 or newer. Full docs: README on GitHub.

Install

  1. Download the zip (do not unzip it).
  2. Blender > Edit > Preferences > Add-ons > drop-down arrow > Install from Disk (older: Install...).
  3. Enable Marble Allstars Tools.
  4. Press N in the 3D viewport and open the Marble tab.

What you get

Drop TesterSpawn empty + rigid-body marble drop or launch, traced paths, text report (max speed, distance, fell off / finished / stopped). Drop a row of marbles to test ramp width.
PlaytestDrive the marble in the viewport: WASD move, Space jump, mouse look, R respawn, Esc stop. Checkpoints, finish timer, kill plane, recorded route.
Level DesignJump-arc preview, launch-speed solver to a target, ramp slope and speed-gained read-out, level stats, JSON settings sync with the Godot project.

# Frogs in the Sky

A chill voxel climbing game about frogs from around the world climbing overgrown sky ruins to reach crystal ponds (and every snack along the way).
It's built in **Godot 4.3** and aimed at **Steam** (Windows, Linux/Steam Deck, macOS).

## Run it
1. Install [Godot 4.3](https://godotengine.org/download) (the standard build, not .NET).
2. Open `frogs-in-the-sky/project.godot` and press **F5**.

## What's in this first slice
- **3 floating dioramas**: *The Overpass*, *Rooftop Cistern* and *Last Bus Stop*. Each has small Zelda-style puzzles:
  - a crate you push onto a pressure plate, which drops a giant road sign into a ramp
  - seeds you lick up and plant in soft soil, which grow vines you climb with sticky toes
  - a dry water tower that you fill with a valve so a raft floats you up
  - a billboard and a plank that spin on poles (turn them in focus mode) to make bridges
  - a two-plate gate: one crate plus one very large buddy frog (croak to call it, croak again to make it wait; it hops onto a plate)
- **100 frog species** in the Frog Book (`scripts/frog_species.gd`). Snacks and finished levels unlock more, and you can play as any frog you've unlocked.
- **Sticky hands**: walk or jump into rough walls (brick, concrete, wood, stone) to cling and climb.
  - You get about 0.8 s of grip (about 2 m), which refills when you land. Jump while clinging to wall-jump.
  - Smooth metal (fences, gates, signs, tiles) is slippery, so the puzzles can't be skipped.
- **Real-time physics junk**: cones, tires, cans, bottles, buckets, flower pots and oil drums are rigid bodies.
  - Bump them, yank them with your tongue, flatten them with a big landing, or blast them with a croak.
  - Heavy junk (tires, drums, pots) can even hold down pressure plates.
- **The world grows as you climb**: flowers, wisteria and saplings sprout as you reach new heights.
- **Life**: idle frogs that croak back when you croak, crows that flap off when you get close, and the Snack Dish.
- **Focus mode** (Tab / Q / right mouse, or LT / LB on a controller): time slows, the camera moves in with a shallow depth of field, you cycle through objects to read about them, and you can interact from a distance.

## Controls
| Action | Keyboard / Mouse | Controller |
|---|---|---|
| Move | WASD / arrows | Left stick |
| Camera / zoom | Mouse / wheel | Right stick / D-pad up-down |
| Hop (hold for higher) | Space | A |
| Tongue (snacks, seeds) | F / left click | X |
| Interact | E | Y |
| Croak | C | B |
| Focus mode, then next item | Tab, Q or right click, then A / D | LT or LB, then RB / D-pad |
| Pause | Esc | Start |

## Graphics settings (Settings > Graphics)
- Quality presets: Low, Medium, High, Ultra.
- Window mode, V-Sync, frame-rate cap, render scale, and upscalers (Bilinear, FSR 1, FSR 2.2).
- Anti-aliasing: FXAA, MSAA 2x/4x, TAA, or TAA + MSAA.
- Shadows up to 8K soft.
- SSAO, SSIL, SDFGI global illumination, volumetric fog with light shafts, and bloom.
- Depth of field: Off, Subtle or Cinematic, with a strength slider, plus the tilt-shift "diorama" blur.
- Foliage density.

Camera: FOV, sensitivity, invert X/Y, auto-follow and shake. Audio: separate Master, Music, Ambience and Effects sliders.

## Audio
All sounds are generated by `tools/gen_audio.py` (numpy), so they're ours and fine to ship on Steam.
- Everything is soft-attack and low-passed to about 4–5 kHz, so there are no piercing highs.
- The Master bus also has a 7.5 kHz low-pass and a limiter.
- Sounds: a lo-fi pad and kalimba loop, wind, water, distant birds and crows, three croaks, and hops, plops, chimes and puzzle jingles.
- To change them, edit the script and run `python3 tools/gen_audio.py`.

## Tests
A headless playtest drives the real frog with simulated input and solves every puzzle in all three levels:
```
godot --headless --path frogs-in-the-sky res://tests/test_runner.tscn
```
To render screenshots (needs a display, or Xvfb):
```
SHOT_DIR=/tmp/shots godot --rendering-driver opengl3 --path frogs-in-the-sky res://tests/shots.tscn
```

## Code map
| File | What |
|---|---|
| `scripts/main.gd` | world/environment, level flow, focus mode |
| `scripts/level.gd` | diorama building kit (voxel blocks, foliage, vines, props, pond) and runtime (snacks, growth) |
| `scripts/levels.gd` | the three level layouts |
| `scripts/props.gd` | snacks, seeds, soil, crates, plates, movers, valves, rotators, NPC and buddy frogs, crows |
| `scripts/player.gd` | the frog controller (hop, sticky-toe climbing, tongue, croak) |
| `scripts/frog_model.gd`, `voxel.gd` | procedural voxel frogs and the voxel mesher (face culling + vertex AO) |
| `scripts/camera_rig.gd` | diorama camera with tilt-shift and focus depth of field |
| `scripts/ui.gd` | title, HUD, pause, settings, Frog Book, level complete |
| `scripts/game.gd`, `sfx.gd` | settings/save/input map, audio |
